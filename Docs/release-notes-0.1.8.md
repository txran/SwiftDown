# SwiftDown 0.1.8 发行说明

预览从「只读渲染」变成**能直接改字的阅读模式**。点一下正文就能就地打字，
不用切到源码模式，也不用先找一个按钮。

## 改了什么

上一版是「鼠标悬停 → 右上角冒出铅笔 → 点开弹出一个源码编辑框」。这个交互有三个问题：
按钮大小跟着块走、到处冒铅笔很吵、点开看到的是 `**粗体**` 源码而不是你读到的文字。

现在：

- **直接点正文**，光标落在你点的那个字上，可以立刻打字。
- 编辑时**看到的就是渲染后的样子**：粗体还是粗的、行内代码还是等宽的、链接还是蓝色，
  只有光标所在的那一行会把 `**` `` ` `` 这些标记显形（免得你改到一半不知道自己在改什么）。
- 点别处 / `⌘↩` 提交，`Esc` 放弃。
- 代码块**双击**进入编辑（它里面要能选中、能横向滚，所以单击留给了选中）。

**样式仍然在源码模式改**：加粗、改标题层级、插链接、改列表层级这些不在预览里做。
预览里改的是字，格式标记原样保留——改一个错别字不会把这一段的其他格式弄丢。

## 顺带修的

- **点击不会吞掉滚动**：正文上方盖了一层透明的点击接收层，滚轮事件显式转交给外层页面，
  鼠标停在文字上照样能滚。
- **只读文档**（>20MB）自动关掉就地编辑，选中复制照旧可用。
- **纯图片段落**点进去不会变成空框（整块都是标记时会显示原始写法）。
- **代码块围栏不会被挤走**：编辑代码块时只编辑围栏之间的内容。

## 已知限制

- 光标可以停在看不见的标记上（标记是被画成透明的，不是删掉）。光标行会让它们显形。
- **表格**点进去看到的是 `| a | b |` 这样的原始写法，不是表格。改表格内容目前只能这样。
- 长段落折行后，点击落点与光标位置可能有几个字的偏差（排版是离线估算的）。

## 自检

161 → **187 项全通过**。新增的 26 条里，6 条是真实点击链路：

点击层 → 出现编辑器 → 编辑器内容是这一段原文 → 改字 → 失焦提交 → 正文变化 →
编辑器收起 → 标题没被波及。

其余是样式层断言：标记识别（含 `snake_case` 里的下划线不算强调）、
隐藏后字号 0.1pt、光标行恢复字号、隐藏不改变字符本身、代码块区间去掉围栏、
点击落点换算成字符下标。
