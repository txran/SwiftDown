# SwiftDown 0.1.0（M1 首个发行版）

macOS 上的轻量 Markdown 编辑器：左边写，右边即时看。基于 SwiftUI + AppKit，
四层架构、状态机驱动，自带 65 项无头端到端自检。

## 下载

| 文件 | 说明 |
|---|---|
| `SwiftDown-0.1.0-arm64.dmg` | 推荐。打开后把 SwiftDown 拖进「应用程序」 |
| `SwiftDown-0.1.0-arm64.zip` | 解压即用 |

- 仅 **Apple Silicon（arm64）**，要求 **macOS 13 Ventura** 及以上
- ad-hoc 签名（无开发者证书）。首次打开若提示「无法验证开发者」：
  - 访达中右键 App → **打开** → 再点「打开」；或
  - 终端执行 `xattr -dr com.apple.quarantine /Applications/SwiftDown.app`

## 功能

- **三态视图**：仅源码 / 分屏 / 仅预览，右下角一点即切，快捷键 ⌘1 ⌘2 ⌘3
- **实时预览**：输入停顿 200ms 后解析；标题、列表、表格、代码块、引用、行内样式全部支持
- **大纲导航**：标题层级自动生成，点击跳转
- **行号与语法高亮**：按逻辑行编号，自动换行的续行不重复标号；行号可关闭
- **多标签**：拖拽排序、右键（复制路径 / 访达中显示 / 关闭其他）；
  标签放不下时可配「单行 + 滚动箭头」或「多行换行（≤3 行）」
- **自动保存**：停止输入 2 秒后落盘，切标签 / 失焦 / 退出前强制保存
- **外部修改保护**：文件被其他程序改动时先提示，冲突期间冻结写入，
  由你选择「采用磁盘版 / 用我的版本覆盖 / 另存副本」
- **外观**：跟随系统 / 白天 / 黑夜；4 种等宽字体、字号 ⌘+/⌘−
- **快捷键可改**：设置 → 快捷键，录制式录入，自动检测冲突
- **会话恢复**：记住上次打开的标签与布局；大文件（>20MB）自动转只读，避免卡死

## 已知限制

- 仅 arm64：本机 CLT SDK 无法链接 x86_64 的 SwiftUI 符号，Intel 机器需自行编译
- 未做 App Store 签名与公证，首次打开需手动放行
- 导出 HTML / PDF、图片粘贴、查找替换尚未实现（M2 计划）
