# SwiftDown 0.1.6

## 新增：全局查找与替换，快捷键可在设置里改

`⌘F` 查找、`⌘⌥F` 展开替换、`⌘G` / `⇧⌘G` 上下跳转。两个范围：

- **当前文档**：全文查找（不是只查可见区），`1/3` 计数、上下跳转、可替换。
- **所有标签**：跨已打开文件列出「文件 → 行号 → 片段」，点一下跳过去。替换只在当前文档范围开放。

选项三个开关：区分大小写、整词、正则，鼠标悬停有说明。快捷键默认 `⌘F` / `⌘G` / `⇧⌘G` / `⌥⌘F`，
在「设置 · 快捷键 · 查找」里可改，冲突会自动拦下。

### 为什么没有沿用系统查找栏

`NSTextView` 自带查找栏，两个硬伤：**它的 ⌘F 改不了**（AppKit 内建，接不进可配置的快捷键体系），
**它只搜当前这一个 `NSTextView`**（跨文件搜索得自己来）。所以把 `usesFindBar` 关掉了——
不关的话同一条 `⌘F` 会同时唤出两套界面。

### 三个实现上的取舍

1. **高亮写进 `textStorage`，但把副作用堵死**。当前命中实色、其余 35%，一眼看出「我在第几处」。
   上色期间关掉撤销注册（⌘Z 撤销的永远是你自己的编辑）、只改属性不改字符（不会把文档改脏）、
   记下原有底色（行内代码自己的背景色，清除时原样还回去）。
2. **替换走 `insertText(_:replacementRange:)`**。这是 `NSTextView` 的正规编辑入口，
   撤销注册与委托通知都由它完成。批量替换倒序执行并套一层撤销分组，**N 次替换 = 1 步撤销**。
3. **跳转不抢焦点**。`⌘F` 打完字焦点还在输入框里，跳转只滚动 + 选中 + 系统查找指示器。

## 修复：这一轮抓到的四个问题

| 现象 | 真因 | 修法 |
|---|---|---|
| 正则 `^dog` 搜不到第 2 行行首 | `NSRegularExpression` 默认只认整段文本首尾，不带 `.anchorsMatchLines` 时 `^` 不匹配每行行首 | 构造 options 时默认加上 |
| 替换栏浮在编辑区半空，还顶出一大块空白 | 左侧占位用了 `Color.clear.frame(width:)`——`Color` 两个轴都贪婪，宽度定住而高度没定，整行被撑满、同行控件垂直居中 | 换 `Spacer().frame(width:)` |
| **正文一处高亮都没有**，查找栏却显示 `1/24` | 高亮走的是 TextKit 2 的渲染属性（`addRenderingAttribute`），属性确实登记上了，但**真实窗口里不落色** | 改为写 `textStorage`，见下 |
| 悬停 `Aa` / `W` / `.*` 看不到说明 | 系统默认要停 2–3 秒才弹提示，短标签按钮基本等不到 | 把提示延迟压到 0.6 秒，文案补成完整说明 |

第二条单看查找栏截图看不出来（截图时 host 高度写死，错误被掩盖），把查找栏放回真实窗口渲整窗图才看见。

第三条最值得说，它是「自检全绿、真机全白」的典型案例：

| 检查 | 结果 |
|---|---|
| `enumerateRenderingAttributes` 枚举 | `NSBackgroundColor` **确实挂在命中区间上**（3.7 万字符、47 段登记） |
| 加属性后作废布局片段 + 强制重新布局 | 无效 |
| 加属性后 `needsDisplay` | 无效 |
| 换颜色（系统动态色 → 具体 sRGB） | 无效 |
| 同一 API 换成红色打在另一段 | **画得出来** |
| 离屏渲染（`cacheDisplay`）跑同一份代码 | **画得出来** ← 所以自检一直是绿的 |

改用写 `textStorage` 后立刻正常。这件事改变了自检策略：光靠离屏像素不够，
现在还会「把整窗视图挂起来、跑完首帧、再改查询词」，按真实操作顺序再断言一次。

## 自检

143 项全 PASS（0.1.5 为 82 项）。

查找替换相关新增 21 条，核心是一组**像素级断言**：把探针 `NSTextView` 离屏渲成位图，
数「偏黄」像素并按饱和度分档。

| 状态 | 实色 px | 淡色 px |
|---|---|---|
| 未查找 | 0 | 0 |
| 1 处命中 | 224 | 0 |
| 3 处命中（当前 = 第 1 处） | 224 | 477 |
| 清除后 | 0 | 0 |

实色恰好等于「一处」的量、淡色约等于两处——一次证明三件事：每处都画了、
当前处与其余处层级分得开、清除是干净的。TextKit 2 与显式降级后的 TextKit 1 各跑一遍，数字一致。

另外补了三条**机制断言**（防止再退回渲染属性、或改成用替换文本上色）：命中区间的背景属性确实落在
`textStorage` 里、这次编辑的 `editedMask` 只含 `.editedAttributes`、清除后行内代码原底色被还原；
以及一条**真实路径**断言：视图先挂好、跑完首帧，再改查询词，断言编辑器出现高亮、
且「下一处」把选区推到第 3 处。

## 安装

下载 `SwiftDown-0.1.6-arm64.dmg`，拖进「应用程序」。首次打开若提示无法验证开发者，
右键 → 打开，或执行：

```bash
xattr -dr com.apple.quarantine /Applications/SwiftDown.app
```

仅 Apple Silicon（arm64），macOS 13+。
